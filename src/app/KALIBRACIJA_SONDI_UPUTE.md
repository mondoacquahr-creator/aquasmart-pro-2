# 🔬 Detaljne Upute za Kalibraciju pH Sondi

## 📋 **KOMPLETNA PROCEDURA KALIBRACIJE pH SONDE**

### ✅ **PRIPREMA:**

**Prije kalibracije:**
1. ✅ Isperite sondu **destiliranom vodom**
2. ✅ Nježno obrišite sondu
3. ✅ Pripremite kalibracijske otopine prema uputi na uređaju:
   - pH 4.01 (kisela točka)
   - pH 7.00 (neutralna točka)
   - pH 10.01 (lužnata točka - opciono)

---

### 🌡️ **TEMPERATURA I TABLICA KOREKCIJE:**

**KLJUČNO:**
- Stavite elektrodu u otopinu na **preporučenu temperaturu**
- Većina buffer otopina je kalibrirana na **25°C**
- Ako temperatura nije 25°C → upotrijebite **priloženu tablicu korekcije**

#### **Tablica Temperaturne Korekcije:**

```
┌──────────────────────────────────────────┐
│  pH 4.01 Buffer:                         │
│  • 0°C  → pH 4.01                        │
│  • 25°C → pH 4.01 (referentna)           │
│  • 50°C → pH 4.02                        │
├──────────────────────────────────────────┤
│  pH 7.00 Buffer:                         │
│  • 0°C  → pH 7.12  (+0.12)               │
│  • 25°C → pH 7.00  (referentna)          │
│  • 50°C → pH 6.88  (-0.12)               │
├──────────────────────────────────────────┤
│  pH 10.01 Buffer:                        │
│  • 0°C  → pH 10.32 (+0.31)               │
│  • 25°C → pH 10.01 (referentna)          │
│  • 50°C → pH 9.82  (-0.19)               │
└──────────────────────────────────────────┘
```

**PRIMJER:**
Ako kalibrirate na **15°C** umjesto 25°C:
- pH 7 buffer će pokazivati ~7.06 (umjesto 7.00)
- To je normalno! Uzmite u obzir temperaturnu korekciju

---

### 🔧 **KALIBRACIJA - KORAK PO KORAK:**

#### **TOČKA 1: pH 7.0 (Neutralna)**

```
1. Uronite sondu u pH 7.0 otopinu
2. Pričekajte da se očitanje STABILIZIRA (1-2 minute)
   → Gledajte da brojka prestane skakati
3. Pritisnite "CAL" na uređaju
4. Izvršite kalibraciju prema uputama instrumenta
   → Obično: Pritisnite "CONFIRM" ili "ENTER"
5. Pričekajte potvrdu kalibracije
```

#### **ISPIRANJE:**
```
✅ Isperite sondu destiliranom vodom nakon pH 7
✅ Nježno obrišite (bez trljanja!)
```

#### **TOČKA 2: pH 4.0 (Kisela)**

```
1. Uronite sondu u pH 4.0 otopinu
2. Pričekajte stabilizaciju očitanja
   → Ponovno 1-2 minute
3. Potvrdite kalibraciju na uređaju
   → Uređaj će automatski prepoznati pH 4
```

---

### 🧪 **ZAVRŠNO ISPIRANJE I POHRANA:**

**ISPIRANJE:**
```
1. Naknadno isperite sondu destiliranom vodom
2. NE obrišite suhom krpom!
3. Lagano protresite višak vode
```

**POHRANA:**
```
✅ Pohranite prema preporuci proizvođača
✅ Obično: KCl 3M otopina za skladištenje
❌ NIKADA ne čuvajte u destiliranoj vodi!
❌ NIKADA ne ostavljajte sondu suhu!
```

---

### ✅ **PROVJERA KALIBRACIJE:**

**Nakon kalibracije:**
```
1. Stavite sondu natrag u pH 7.0 otopinu
2. Očitanje bi trebalo pokazati: 7.0 ± 0.1
3. Ako pokazuje 6.9 ili 7.1 → OK! ✅
4. Ako pokazuje 6.5 ili 7.5 → Ponovite kalibraciju!
```

## ⚠️ **KRITIČNA UPOZORENJA:**

### 🔴 **OTOPINE:**
```
⚠️ Koristite SVJEŽE kalibracijske otopine
   → Provjerite ROK TRAJANJA!

⚠️ NIKADA ne vraćajte korištenu otopinu u bocu
   → Kontaminacija!

⚠️ Buffer otopine mogu trajati otvorene samo:
   → 3-6 mjeseci nakon otvaranja
```

### 🔴 **SONDA:**
```
⚠️ Sonda mora biti POTPUNO uronjena
   → Keramička membrana mora biti pokrivena

⚠️ NE obrišite sondu SUHOM krpom
   → Samo destilirana voda!

⚠️ Temperatura otopine utječe na očitanje
   → Koristite tablicu korekcije
```

### 🔴 **SKLADIŠTENJE:**
```
⚠️ NIKADA ne čuvajte sondu u destiliranoj vodi
   → Sonda će se isušiti i prestati raditi

⚠️ Čuvajte u KCl 3M otopini
   → Ili prema uputi proizvođača

⚠️ Ako se sonda osuši:
   → Namočite u KCl 24h prije korištenja
```

## 💡 **PROFESIONALNI SAVJETI:**

### ✅ **TEMPERATURA:**
```
💡 Najbolje je kalibrirati na temperaturi BLIZU
   temperature bazenske vode
   
💡 Ako bazen ima 26°C, kalibrirajte na ~25°C
   
💡 ATC (Automatic Temperature Compensation):
   → Moderna sonda automatski korigira temperaturu
   → Provjerite da li vaša sonda ima ATC
```

### ✅ **REDOSLIJED:**
```
💡 UVIJEK prvo pH 7 (neutralna točka)
   → Pa onda pH 4 ili pH 10

💡 Zašto? pH 7 je OSNOVNA referentna točka
   → Sve ostale točke se izračunavaju od pH 7
```

### ✅ **STABILIZACIJA:**
```
💡 Pričekajte da očitanje PRESTANE SKAKATI
   → Ne žurite!
   
💡 Ako očitanje skače 7.02 → 7.01 → 7.00 → 7.01
   → To je normalno, pričekajte
   
💡 Ako očitanje skače 7.2 → 6.8 → 7.3
   → Sonda možda treba čišćenje ili zamjenu
```

### ✅ **DNEVNIK ODRŽAVANJA:**
```
💡 Zapišite:
   - Datum kalibracije
   - Temperatura kalibracije
   - Rezultat (npr. "pH 7.0 pokazuje 7.01")
   - Lot broj buffer otopine
   
💡 Ovaj dnevnik pomaže kod troubleshooting-a
```

### ✅ **VERIFIKACIJA:**
```
💡 Nakon kalibracije, testirajte u SVIM otopinama:
   - pH 7 → trebao bi biti 7.0 ± 0.1
   - pH 4 → trebao bi biti 4.0 ± 0.1
   
💡 Ovo je PROVJERA da li je kalibracija uspješna
```

## 🔄 **ATC (Automatska Temperaturna Kompenzacija):**

### **Što je ATC?**
```
✅ Moderna sonda ima temperature sensor
✅ Automatski korigira pH očitanje prema temperaturi
✅ NE trebate ručnu tablicu korekcije
```

### **Kako Provjeriti:**
```
1. Pogledajte specifikaciju sonde
2. Ako piše "ATC" ili "Automatic Temperature Compensation" → Imate!
3. Ako ne piše → Morate ručno koristiti tablicu
```

### **Sa ATC:**
```
✅ Sondu možete kalibrirati na bilo kojoj temperaturi
✅ Sonda automatski prilagođava očitanje
✅ Još uvijek pričekajte stabilizaciju!
```

### **Bez ATC:**
```
⚠️ Morate kalibrirati na TOČNOJ temperaturi (25°C)
⚠️ Ili koristiti tablicu korekcije
⚠️ Manual korekcija je manje točna
```

## 🛠️ **TROUBLESHOOTING:**

### Problem: "Očitanje ne stabilizira"
```
→ Sonda možda treba čišćenje
→ Provjerite da li je sonda potpuno uronjena
→ Provjerite rok trajanja buffer otopine
→ Sonda možda treba zamjenu
```

### Problem: "Kalibracija ne prolazi"
```
→ Buffer otopina možda nije svježa
→ Sonda možda ima naslage - očistite
→ Temperatura previsoka ili preniska
→ Keramička membrana oštećena
```

### Problem: "Pokazuje pogrešne vrijednosti"
```
→ Ponovite kalibraciju
→ Očistite sondu
→ Provjerite skladištenje (u KCl?)
→ Možda treba nova sonda
```
