## 📦 Setup Koraci:

### 1. Kreiraj Folder:

```bash
mkdir aquasmart-pro
cd aquasmart-pro
```

### 2. Kopiraj package.json (vidi dolje)

### 3. Install Dependencies:

```bash
npm install
```

### 4. Kopiraj Sve Source Fajlove

### 5. Run:

```bash
npm run dev
```

---

## 🚀 Ili Brži Način: Figma Make Export

U Figma Make IDE-u:

1. **File menu** (gore lijevo)
2. **Export Project** ili **Download**
3. Skineš ZIP
4. Unzip
5. `npm install`
6. `npm run dev`

Gotovo! ✅
