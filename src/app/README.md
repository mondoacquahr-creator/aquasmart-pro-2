# 🏊 AquaSmart Pro - Pool Water Analysis

Ultra moderna aplikacija za profesionalnu analizu bazenske vode sa Ivero proizvodima.

## ✨ Features

- 🧪 **Analiza vode** - pH, klor, ORP, alkalnost, tvrdoća
- 💊 **Dosing Engine** - Točno doziranje Ivero proizvoda
- 📊 **Povijest analiza** - Praćenje kroz vrijeme
- 👥 **Klijenti** - Profesionalni mod
- 🗺️ **GPS Lokacije** - Praćenje bazena
- 🎨 **Moderni UI** - Glassmorphism, gradients, animations
- 📱 **PWA** - Install kao native app
- 🔄 **Offline** - Radi bez interneta

## 🚀 Quick Start

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## 📱 Deploy na Mobitel

### Vercel (Preporučeno):

```bash
npm install -g vercel
vercel
```

Otvori URL na mobitelu → "Add to Home Screen"

### Local Network:

```bash
npm run dev -- --host
```

Otvori `http://192.168.1.X:5173` na mobitelu
