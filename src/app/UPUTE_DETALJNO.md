# 📚 Detaljne Upute za Održavanje Bazena

## 🔵 ISPIRANJE FILTERA - Kompletna Teorija

### ⚙️ **ŠTO JE POVRATNO ISPIRANJE (BACKWASH)?**

**FUNKCIJA:**
Povratno ispiranje je odvajanje taloženih nečistoća iz filterskog pijeska.

**PRINCIP RADA:**
Ispiranje se postiže **promjenom smjera protoka vode**:
- Normalno: Voda ide GORE → DOLJE kroz pijesak
- Backwash: Voda ide DOLJE → GORE (suprotno)
- Nečistoće se ispiru van kroz odvodni otvor

---

### ⚠️ **UVJETI ZA POVRATNO ISPIRANJE:**

**Morate isperati filter kada:**

1. **Tlak se povećao:**
   - Očitanje manometra je **50 kPa (7.2 psi)** VEĆE od početnog tlaka
   
2. **Brzina protoka se smanjila:**
   - Brzina protoka vode kroz sloj filtera smanjuje se sve dok ne postane **nedovoljna da zadovolji potrebe**

3. **Kvaliteta vode opada:**
   - Učinkovitost uklanjanja filterskog sloja smanjuje se do točke u kojoj se **kvaliteta vode pogoršava** i više nije prihvatljiva

---

### 🚨 **VAŽNOST POVRATNOG ISPIRANJA:**

**⚠️ POVRATNO ISPIRANJE JE VRLO BITNO!**

**Što se događa BEZ pravilnog ispiranja:**

1. **Filterski medij postaje "nabijen":**
   - Bez pravilnog i dovoljno čestog ispiranja, gusti filterski medij može postati "nabijen"
   
2. **Stvaraju se kanali:**
   - Krhotine ostaju zarobljene i stvaraju **kanale unutar sloja filtera**
   
3. **Filter ne radi:**
   - Voda "preskače" kroz kanale umjesto da se filtrira
   
4. **Voda postaje sve prljavija:**
   - Sloj filtera postaje sve prljaviji kako vrijeme prolazi
   
5. **Neefikasan rad:**
   - Rad filtera postaje **potpuno neefikasan**

---

### 📊 **KADA TOČNO ISPERATI:**

#### ✅ **Indicator #1: Manometar (Tlak)**

```
Početni tlak nakon čistog ispiranja: 100 kPa
Trenutni tlak:                       150 kPa
Razlika:                             50 kPa  ← VRIJEME ZA BACKWASH!
```

**⚠️ VAŽNA NAPOMENA:**
- Ako je filter spojen na **vodovodnu mrežu**, porast tlaka **NIJE točan pokazatelj**
- Mrežni tlak ima tendenciju **fluktuacije**
- **NAJBOLJE:** Osloniti se na **stvarnu brzinu protoka**!

#### ✅ **Indicator #2: Brzina Protoka**

```
Normalna brzina: 15 m³/h
Trenutna brzina: 8 m³/h  ← VRIJEME ZA BACKWASH!
```

---

### 📅 **PREPORUČENA UČESTALOST:**

**💡 PREPORUČUJE SE:**
- **Barem jednom mjesečno** isperite pješčani filter bazena
- Ili **kada tlak poraste za 50 kPa**
- Ili **kada protok padne za 30%**

**Što se događa ako ne isperete:**
1. Rano pražnjenje sloja filtera
2. Krhotine se ne ispiru iz zrna medija
3. Sloj filtera postaje sve prljaviji
4. Rad filtera postaje neefikasan

---

### 🛠️ **KORACI ZA ISPIRANJE:**

#### **PRIPREMA:**
```
1. Očistite košaru pumpe
2. Očistite košare u skimmerima
3. Provjerite manometar
```

#### **BACKWASH PROCEDURA:**

```
┌─────────────────────────────────────────┐
│  1. UGASITE PUMPU                       │
│     → Pričekajte da se voda smiri      │
├─────────────────────────────────────────┤
│  2. OKRENITE VENTIL NA "BACKWASH"       │
│     ⚠️ NIKADA dok pumpa radi!          │
├─────────────────────────────────────────┤
│  3. UPALITE PUMPU                       │
│     → Pustite 2-3 minute               │
│     → Voda mora biti kristalno čista   │
├─────────────────────────────────────────┤
│  4. UGASITE PUMPU                       │
│     → Pričekajte da se zaustavi        │
├─────────────────────────────────────────┤
│  5. OKRENITE NA "RINSE"                 │
│     → Završno ispiranje                │
├─────────────────────────────────────────┤
│  6. UPALITE PUMPU 30-60 SEKUNDI         │
│     → Ispire cijevi                    │
├─────────────────────────────────────────┤
│  7. UGASITE PUMPU                       │
│     → Zadnji put prije normalnog rada  │
├─────────────────────────────────────────┤
│  8. OKRENITE NA "FILTER"                │
│     ⚠️ Provjerite poziciju!            │
├─────────────────────────────────────────┤
│  9. UPALITE PUMPU                       │
│     ✅ Normalan rad vraćen             │
├─────────────────────────────────────────┤
│ 10. ZAPIŠITE DATUM I TLAK               │
│     → Dnevnik održavanja               │
└─────────────────────────────────────────┘
```

---

### ⚠️ **KRITIČNA UPOZORENJA:**

```
🔴 NIKADA ne okrećite ventil dok pumpa radi!
   → Može doći do oštećenja ventila i filtera

🔴 Provjerite da je ventil na "FILTER" poziciji!
   → Prije svakog uključivanja

🔴 Nemojte se oslanjati samo na tlak ako ste na vodovodu!
   → Koristite brzinu protoka kao pokazatelj

🔴 Gusti filterski medij može postati "nabijen"!
   → Bez redovnog ispiranja
```

---

### 💡 **PROFESIONALNI SAVJETI:**

```
✅ Vodite DNEVNIK ODRŽAVANJA:
   - Datum ispiranja
   - Početni tlak
   - Brzina protoka
   - Kvaliteta izlazne vode

✅ Prije ispiranja:
   - OBAVEZNO očistite košaru pumpe
   - OBAVEZNO očistite košare u skimmerima

✅ Pratite izlaznu vodu:
   - Mora biti kristalno čista
   - Ako je mutna → nastavite ispiranje

✅ Provjera brzine protoka:
   - NAJBOLJI pokazatelj
   - Ne samo tlak!

✅ Redovno ispiranje:
   - Produljuje životni vijek pijeska
   - Filter radi maksimalno učinkovito
   - Sprječava "nabijanje" medija
```

---

## 📖 **ZAKLJUČAK:**

**Povratno ispiranje je:**
- ✅ VRLO BITNO za rad filtera
- ✅ MORA se raditi barem MJESEČNO
- ✅ SPRJEČAVA stvaranje kanala
- ✅ ODRŽAVA kvalitetu vode
- ✅ PRODULJUJE životni vijek opreme

**Bez ispiranja:**
- ❌ Filter postaje "nabijen"
- ❌ Stvaraju se kanali
- ❌ Voda nije filtrirana
- ❌ Kvaliteta opada
- ❌ Neefikasan rad

---

**💡 ZAPAMTITE:**
> "Redovno ispiranje = čista voda + dugotrajnost opreme!"

**📅 PREPORUČENO:**
> Jednom mjesečno ili kada tlak poraste za 50 kPa (7.2 psi)

**⚠️ NAJVAŽNIJE:**
> NIKADA ne okrećite ventil dok pumpa radi!
