## 🛡️ PRVA 30 DANA (Važno)

### 4. Registracije (ako planiraš long-term)
- [ ] Registriraj žig "AquaSmart Pro" (DZIV - ~700-1000 kn)
- [ ] Razmotri EU žig (EUIPO - ~850 EUR)
- [ ] Registriraj autorska prava (DZIV - ~500 kn) - opcionalno

### 5. Android Build (za Google Play)
- [ ] Odaberi build metodu: Capacitor / React Native / PWA
- [ ] Dodaj ProGuard obfuscation (`minifyEnabled true`)
- [ ] Implementiraj Play Integrity API
- [ ] Aktiviraj Play App Signing u Google Play Console
- [ ] Test anti-tamper provjere

### 6. Backend sigurnost (ako koristiš Supabase)
- [ ] Svi API ključevi u `.env.local` (nikad u kodu!)
- [ ] Supabase Row Level Security (RLS) aktiviran
- [ ] Osjetljiva logika (pricing, scoring) na backend
- [ ] Edge Functions za tajne algoritme
